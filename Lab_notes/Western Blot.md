插入梳子,待$15min$后上层胶凝固,使用纸包住制胶框,写上日期,孔数,凝胶百分比,姓名.然后用蒸馏水浸泡放于冰箱内.
2. 电泳
	上样:将蛋白样品从-20°C取出,95°C加热5min,短暂离心后按实验设计上样(每孔20-30µg蛋白),Marker孔上样3-5µL,空孔用1×SDS上样缓冲液补齐体积.
	采用两步电泳法,浓缩阶段使用80-100V,待溴酚蓝指示剂进入分离胶之后,将电压提高至120-150V.在4摄氏度条件下电泳可以减少热效应导致的条带扩散.待溴酚蓝指示剂到达凝胶底部(或距底部约0.5cm)时停止电泳.

3. 转膜
	1. 准备膜:将PVDF膜剪成与凝胶相近的大小,在一角剪缺口做标记,放入甲醇(或75%酒精)中活化1-2min,再与滤纸,海绵垫一同放入预冷的转膜液中平衡10-15min.全程戴手套,避免用手直接接触膜.
	2. 剥胶:电泳结束后取下玻璃板,用撬板小心撬开,切去浓缩胶和边缘多余部分,将凝胶放入转膜液中平衡5-10min.
	3. 组装“三明治”:从负极(黑面)到正极(白面)依次放置 海绵垫-滤纸-凝胶-PVDF膜-滤纸-海绵垫,每放一层用滚轮或玻璃棒赶走气泡,保证凝胶与膜之间无气泡.
	4. 转膜:将转膜夹按黑对黑,白对红放入转膜槽,加入预冷转膜液至没过凝胶,槽内放冰盒,恒流200-300mA(或恒压100V)转膜1-2h,于4°C或冰浴中进行.分子量越大所需时间越长,小分子可适当缩短.
	5. 验膜(可选):转膜后用丽春红染色1-2min,观察条带是否清晰,再用TBST洗净.

4. 封闭
	将膜放入5%脱脂奶粉/TBST中,室温摇床封闭1h,也可4°C过夜.检测磷酸化蛋白时改用5%BSA/TBST封闭,避免奶粉中的酪蛋白干扰.

5. 一抗孵育
	按抗体说明书用5%BSA或5%脱脂奶粉/TBST稀释一抗(常用1:1000).将膜放入孵育盒,加入一抗溶液至完全覆盖膜,4°C摇床孵育过夜(或室温2h).一抗可回收,按说明书保存并重复使用.

6. 洗膜
	用TBST洗膜3次,每次10min,摇床.

7. 二抗孵育
	按说明书用5%脱脂奶粉/TBST稀释HRP标记二抗(常用1:5000-1:10000),室温摇床孵育1h.

8. 洗膜
	用TBST洗膜3次,每次10min.

9. 显影
	ECL显影液A液与B液按1:1避光混合,滴加在膜上孵育1-2min,用纸巾吸去多余液体,放入成像仪曝光并保存图像.具体操作见[[显影操作方案]].

### 试剂配制(参考)

| 试剂 | 配方 |
| --- | --- |
| 电泳缓冲液(1×) | 25mM Tris,192mM 甘氨酸,0.1% SDS,pH 8.3 |
| 转膜缓冲液 | 25mM Tris,192mM 甘氨酸,20% 甲醇(一般不加SDS,大分子可加0.05% SDS) |
| TBST | 1×TBS + 0.1% Tween-20 |
| 封闭液 | 5% 脱脂奶粉/TBST,现配现用 |
| 显影液 | A液:B液=1:1,避光现配 |

### 注意事项
- 转膜槽中放冰盒或置于冰浴,防止缓冲液过热.
- 凝胶与膜之间不能有气泡,否则对应位置无信号.
- 封闭液和抗体稀释液现配现用;奶粉溶液易变质.
- 洗膜要充分,否则背景偏高.
- 显影液需避光保存,现配现用;曝光时间根据信号强弱调整.
