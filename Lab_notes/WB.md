# WB（Western Blot）图中的核心要素

一张标准的 WB 结果图通常包含以下要素：

## 一、图像本身可见的要素

1. **目的蛋白条带（Target band）**：你要检测的目标蛋白，位置对应其分子量。
2. **内参条带（Loading control）**：见下方详解。
3. **Marker / 分子量标准**：图边缘或标注的分子量刻度（如 35 kDa、55 kDa），用于定位条带。
4. **泳道（Lane）**：每个样品占一列，通常标注样品名/分组。
5. **条带强度**：反映蛋白相对表达量，需定量分析（灰度值）。

## 二、你老师说的"内参"是什么

**内参（Loading control / 上样对照）** 是每个泳道都跑、且理论上**表达量恒定**的蛋白，作用是：

- **校正上样量差异**：不同泳道加的蛋白总量可能不一致，用内参归一化后才能公平比较目的蛋白。
- **证明操作没问题**：内参条带均匀 = 上样一致、转膜均匀、显影正常。

**常用内参**（按样本类型选）：
- 全细胞/组织：**GAPDH、β-actin、Tubulin**
- 核蛋白：**Histone H3、Lamin B**
- 线粒体：**COX IV、VDAC**
- 膜蛋白：**Na/K-ATPase**

## 三、"内参没调好"是什么意思

指上一组的 WB 图中**内参条带各泳道深浅不一**（有的粗有的细、有的没有），说明：
- 各孔上样蛋白量不一致；
- 或转膜/显影不均。

后果：目的蛋白的差异**无法判断是真实生物学差异还是上样误差**，数据不可用，所以要重跑。

## 四、调好内参的实操建议

1. **先测浓度**（BCA 法），按等量蛋白上样（如每孔 20–30 μg）。
2. **上样前混匀、短暂离心**，避免挂壁导致加样不准。
3. **同一批胶、同一转膜条件**，目的蛋白和内参可同膜跑（分子量差异大时）或分别跑。
4. **先跑内参预实验**：确认各泳道条带均匀，再做目的蛋白。
5. 显影时避免过曝，保证条带在**线性范围**内。

---

**一句话总结**：WB 图 = 目的蛋白条带 + 内参条带 + Marker + 泳道标注；内参是"公平秤"，没调好就说明各孔上样不均，数据不可信，必须重跑。
